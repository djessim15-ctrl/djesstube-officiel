# DjessTube — le webtoon

Épisode 1 : **Zéro pub**. Léo, excédé par les pubs de 30 secondes, code son propre
lecteur vidéo ; sa petite sœur Awa profite du résultat.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | lecteur vertical (webtoon) aux couleurs de DjessTube |
| `djesstube-ep1_A5.pdf` | édition papier **A5** (148 × 210 mm), 7 pages, 300 dpi |
| `out/ep1_strip.jpg` | bande verticale complète (lettrage inclus) |
| `panneaux/` | les 6 planches brutes (sans texte) |
| `build.py` | regénère la bande et le PDF : `python3 webtoon/build.py` |
| `fonts/` | lettrage (Bangers + Comic Neue, OFL) |
